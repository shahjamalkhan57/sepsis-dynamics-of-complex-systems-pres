# Sepsis: Dynamics of Complex Systems — Presentation

An interactive classroom simulation of sepsis, shown as the dynamics of a complex system. It follows one illustrative 48-hour sequence inside a single blood vessel: infection, immune response, vessel inflammation, circulation problems and critical illness, with an option to start treatment at any point and compare earlier versus later intervention.

**Live presentation:** https://shahjamalkhan57.github.io/sepsis-dynamics-of-complex-systems-pres/

## How to use

- Open the live link above, or download `index.html` and open it in any modern browser. No install needed.
- Press Play, or drag the timeline. The colored bands are the phases of this example.
- Pause freezes the whole scene so you can look around. Hover any cell or molecule to identify it.
- Press Start treatment at any point to see how the example changes.

## Notes

- Educational material only. The sequence, timing and outcomes are illustrative examples, not medical predictions or advice.
- The example shows Gram-negative bacteria entering through a wound. Real sepsis can start from many kinds of infection and does not follow a fixed clock.
- Built as a single self-contained HTML file (canvas animation, no dependencies beyond a web font).
